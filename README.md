# Software Academy Website
Premium responsive software courses website built with HTML5, CSS3, Vanilla JavaScript, Bootstrap 5, Font Awesome and Google Fonts.

## Run
Open `index.html` in a browser or deploy the folder to Netlify/GitHub Pages.

## Course details
Every course's **View Details** button opens:
`course-details.html?course=COURSE_ID`
in a new browser tab. Course data is stored in `js/courses.js`.

## Important
Replace `https://example.com/` in canonical/robots/sitemap with your real domain before publishing.
The image URLs use high-resolution Unsplash images and require internet access when deployed.
